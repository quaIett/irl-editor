# Обновление ядра IRL Redactor до 1.1.7

Обновлены main (Minecraft 1.20.4) и port/1.20.1, port/1.21.1, port/1.21.4, port/1.21.11. В каждой версии зависимость и вложенный irl-core обновлены до 1.1.7 вместе с семью каноническими шейдерными патчами из принятого BBS-аддона. Java-код и интерфейс редактора не менялись.

Ядро для Minecraft 1.21.4 актуализировано отдельно: общая реализация совпадает с принятой линией 1.21.1, сохранены адаптации BlockShadowCollector и ShadowRenderer под Minecraft 1.21.4. Эксперимент hard-shadows не включён.

Проверки: пять сборок PASS; в каждом JAR ровно одно соответствующее его Minecraft ядро, семь актуальных патчей, все вложенные зависимости и классы миксинов. SHA256 выдачи сверены. Для ядра 1.21.4 прошли существующие проверки GPU upload/profile registry, block-cache, overlays, VRAM budget, caster pool и pipeline.

17 сентября 2026 пользователь закрыл задачу и поручил коммит после запуска и перезапуска 1.21.11. Эту версию приняли по контексту текущего игрового теста; отдельного подтверждения игрового теста остальных четырёх версий нет. Автоматические проверки всех пяти версий завершены. Публикация релиза и push не входят в этот чекпоинт.
